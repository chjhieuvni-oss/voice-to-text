# Voice-To-Text Toolbar (Windows)

A lightweight, high-performance floating voice-to-text toolbar for Windows with AI refinement (Google Gemini), mouse-free clipboard paste & enter, smooth mouse wheel simulation, and full Remote Desktop (RustDesk) compatibility.

## Features
- **Speech-to-Text**: Fast bilingual Vietnamese + English speech recognition with instant clipboard copy.
- **AI Refinement**: Auto grammatical & context correction with Google Gemini.
- **Mouse-free Control**: Instant Select All (A), Copy (C), Paste (V), Enter (↵), Up (▲), Down (▼) buttons without moving or seizing the mouse cursor.
- **RustDesk & Remote Desktop Compatibility**: Full hardware scancodes (`SendInput`) and adaptive network clipboard sync delay.
- **Customizable UI Scale**: 1.0x to 7.5x with real-time hot-reloading.
- **Auto-Update**: Seamless updates via GitHub Releases.
